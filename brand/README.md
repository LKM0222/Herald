# 브랜드 자산

원본을 여기 둔다. 앱이 쓰는 파일은 여기서 파생된 것이라 **원본이 없으면 다시 만들 수 없다.**

| 원본 | 파생 | 쓰이는 곳 |
|---|---|---|
| `logo_simple.png` | `client/src/assets/{mark,lockup}-{light,dark}.png` | 앱 헤더 · 첫 화면 |
| `logo_light.jpg` | `client/public/{favicon,apple-touch-icon}.png` | 브라우저 탭 · 폰 홈화면 |

**용도가 갈리는 이유:** 심플 버전은 단색이라 배경을 투명하게 뽑을 수 있어서 테마와 섞인다.
컬러 버전은 16px 파비콘에서 형태만으로는 안 읽히는 자리에 쓴다 — 빨간 볏이 식별점이 된다.

파생 파일은 `logo_simple.png` 를 세 칸(라이트·다크·회색)으로 나눠 자르고,
배경 밝기를 기준으로 알파를 정규화해 만들었다. 고정 임계값을 쓰면 다크 패널
배경(#1a1d21)이 옅게 남는다.
